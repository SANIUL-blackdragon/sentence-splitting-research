## Files in this folder

- `ch2.3-study-guide.html` / `ch2.4-study-guide.html` — compiled chapter study guides (read these)
- `ch2.3-exam-readiness-questions.html` / `ch2.4-exam-readiness-questions.html` — practice questions
- `ext-*.html` — compiled extension guides
- `unit2-formula-sheet.html` — formula quick reference

## Naming convention

`ch<unit>.<chapter>-study-guide.html` for chapter study guides, `ch<unit>.<chapter>-exam-readiness-questions.html` for practice, `ext-<name>.html` for extensions, `unit<N>-formula-sheet.html` for formula sheets.
