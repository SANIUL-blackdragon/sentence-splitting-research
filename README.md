# Purpose

The point of this repo is to act as a cloud HDD to store some research on a specific topic. The topic is how to split sentences with algorithms. 
I am working on a project I will open-source later. It has an English TTS feature, and I need to create a splitting layer to be able to split prose per sentence only. This allows me to be have the TTS be able to somewhat stream the audio. Sentence N can be spoken while sentence N+1 or whatever is being generated as audio in parallel, making the UX better. I am not satisfied with my current implementation of the splitting layer. It has bugs and doesn't split exactly where it should in some cases. 
Now, I am aware there are ML models to deal with this but I want as light as possible while simultaneously being as fast as possible even for users with trash machines. Good ML models do not provide me with that. Hence why I am trying to figure out a very light and very fast ruleset/algorithms to allow for good splitting for a smoother streaming UX. 
I might not be as smart as some people on this platform, but incase this helps anyone else, I am keeping this repo public with no promises for the future. I will create a license file later.
